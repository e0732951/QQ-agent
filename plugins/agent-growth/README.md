# agent-growth · 人格成长引擎（QQ Agent 插件）

让机器人里的角色**像真人一样长大**：有生日、年龄随现实时间增长（默认**现实 1 个月 = 虚拟 1 岁**），聊天中的真实经历被自动攒成"成长素材"，攒够一批（或每逢"生日"）就交给模型消化，**让 TA 自己写出一条新的「成长阶段提示词」**——这些提示词每轮注入，TA 的言行随年龄自然长大，且始终以当前人设为锚、不跑偏。

## 装完即用

插件放入 `plugins/agent-growth/` 后**重启 QQ Agent**（或在控制台重载插件）即可。无需任何必填配置：

- 角色自动建档：名字取自宿主人设的 `botName`（小鲸鱼），从 8 岁开始成长（可在设置里改"初始年龄"，只对首次建档生效）；
- 爸爸 QQ 自动读取「鲸鱼娘·女儿版人设」插件里填的号码（也可以在本插件设置里单独填）；
- 模型自动用宿主当前选中的模型（想省钱可在设置里指定"沉淀专用模型"）。

## 它做什么

| 机制 | 说明 |
| --- | --- |
| 🎂 生日与年龄 | 现实 30 天 = 1 岁（可调 1~365 天）；每满一岁自动"消化"一次经历并写入成长档案 |
| 🧠 经历记忆 | 亲身互动（触发消息）+ 宿主消息存档抽样（环境见闻）；爸爸的互动单独标记、优先参考 |
| ✍️ AI 自主添加提示词 | 消化时以**宿主当前人设全文**为锚 + 成长铁律（不冲突/不推翻/保持多模式边界/遵守红线），产出 `{"stageTitle","newPrompt","memorySummary"}` 按岁存档 |
| 📥 每轮注入 | 年龄状态 + 最近 12 个成长阶段（priority 46），生日当天额外注入"今天你过生日" |
| 🛠️ 三个工具 | `growth_report` 查档案 / `growth_stages` 查进化记录 / `growth_mark` 记重要经历（聊天里问"你多大了/你的人设怎么进化的"会自动调用） |
| 📄 可视化档案 | `data/growth/成长档案.html`：年龄环 + 人设进化时间线 + 经历列表，浏览器直接打开 |

## 在哪里查看"AI 自己加的提示词"

1. **聊天里问**：让 TA"看看你的成长档案/你的人设进化记录"（走工具）；
2. **档案页**：`QQ Agent/data/growth/成长档案.html`（时间线最直观，每次沉淀后自动刷新）；
3. **插件设置页**：本插件的设置项 + 各项说明都在 QQ Agent 控制台的插件设置里；动态状态另暴露 `growth.status` 能力（年龄/阶段数/最近阶段/档案路径）；
4. **纯文本**：`data/growth/growth_stages.txt`。

## 与其他扩展的关系（零冲突设计）

- **鲸鱼娘·女儿版人设**：那边管"对谁是女儿模式/朋友模式"（身份切换），这边管"长到几岁、经历过什么"（岁月沉淀）。成长阶段对两种模式一体生效；爸爸 QQ 只读不写。
- **仿真实生活**：那边管"今天"（日程/小事），这边管"岁月与一生"。注入通道（section id）与存储目录（`data/growth/`）完全独立。
- **conversation-memory 等记忆模块**：它们记"和谁聊过什么"，这边记"这些经历把 TA 变成了什么样"。

## 数据与维护

```
QQ Agent/data/growth/
├─ profile.json      角色（名字/性别/生日）——删掉并重启可按新"初始年龄"重建
├─ memories.json     待消化的亲身互动记录
├─ stages.json       ★ AI 自主添加的成长阶段提示词（按岁存档）
├─ state.json        时钟状态（生日已处理标记/水位）
├─ growth_stages.txt 纯文本阶段表
└─ 成长档案.html      可视化档案页
```

- 想让 TA"重生"：关闭插件 → 删除 `data/growth/` → 开启，按设置里的"初始年龄"重新建档。
- 某条成长阶段不满意：编辑 `stages.json` 删掉那一条即可，下次沉淀会重新生成。
- 未配置模型 Key 时：年龄照常增长，生日沉淀自动跳过（只长年龄、性格不变），配置好后恢复正常。
