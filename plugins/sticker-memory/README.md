# 本地资料库（sticker-memory）

图片和视频都按指纹记下描述。同一份内容再出现时，直接读描述，跳过看图或看视频。

插件目录名仍是 `sticker-memory`，原来已经记下的表情包描述会继续用。

- 版本：2.0.0 ｜ API：v1 ｜ 目录：`plugins/sticker-memory/`
- 默认：开。自动遗忘默认关。

## 什么时候会跳过

| 场景 | 发生什么 |
|---|---|
| 第一次见到某张图或某个视频 | 照常看。看完后把描述记进资料库 |
| 同一份内容再来 | 系统在调用看图或看视频之前拦下，把库里的描述交给模型 |
| 描述不对 | 用 `sticker-memory__remember_image` 覆盖，或用 `sticker-memory__forget_cached_image` 删掉 |

认的是内容指纹，不是会过期的链接。图片用字节哈希；视频用 QQ 文件名、B站 BV 号，本地文件还在时再抽样哈希。

## 设置

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用 | 开 | 关掉后不拦截，也不再记录 |
| 资料库上限 | 2000 | 超出后淘汰最久没用到的 |
| 单次取图预算 | 2800 毫秒 | 只用于第一次给图片算指纹 |
| 自动遗忘 | 关 | 打开后才按天数删旧记录 |
| 从多少天前开始遗忘 | 30 | 只在自动遗忘打开时生效。早于这个天数的记录，从最旧的一条开始删 |

## 工具

| 工具 | 什么时候用 |
|---|---|
| `sticker-memory__remember_image` | 第一次看完图片或视频后，写下画面描述 |
| `sticker-memory__list_cached_images` | 查看已经记下的描述 |
| `sticker-memory__forget_cached_image` | 按描述里的词删掉一条 |

数据在本机 `data/sticker-memory/cache.json`。图片视频和热梗分格存放，上限和遗忘各自设置。不写密钥，不改 `data/stickers.json`。
