# GPT-SoVITS 语音回复（sovits-voice-reply）

把机器人**本该打字发出来的回复**，改用你本机 GPT-SoVITS 里自己训练/配置的音色念出来，
以 QQ 原生语音（record 段）发出去。

- 类型：**插件**（确定性型，`plugins/`）。规则写死，**零 token** —— 不注册工具、不写提示词、不叫模型。
- 挂载点：`OneBotClient.prototype.sendText`。核心所有外发文字最后都汇聚到这一个方法，
  插件把它包一层：该转语音就换成 `record` 段（仍走 `sendSegments`），否则原样放行。
- **接口会自动启动**：GPT-SoVITS 语音接口没在跑时，插件自己在后台把它拉起来
  （不弹黑窗口），开机后只要开 QQ Agent 就行，不用再管第二个程序。
- 底线：配置不全 / 接口起不来 / 合成为静音 / 协议端拒收 / 任何异常 → **一律回落成发文字**，消息不会丢。

## 装好之后要填什么

在 QQ Agent 控制台 →「插件」页 → 找到 **GPT-SoVITS 语音回复** → 点「设置」：

| 字段 | 说明 |
|---|---|
| 参考音频（必填） | **必填**。3~10 秒干净人声 wav，音色由它决定 |
| 参考文本（必填） | **必填**。参考音频里原原本本说的那句话，必须逐字一致 |
| SoVITS / GPT 权重（可不填） | 留空 = 直接用你接口端已加载的权重；也可以填**训练模型**或**底模**（见下一节） |
| GPT-SoVITS API 地址 | 默认 `http://127.0.0.1:9880`（`api_v2.py` 默认端口） |
| 接口没运行时自动帮你启动 | 默认开。**但要先把下面三个路径填上**；不填就等于关掉，得自己先开接口 |
| python / api_v2.py / **根目录** | 自动启动用的三个路径；**留空 = 不自动启动**，不是必填。根目录还用来解析下面那些**相对路径**的权重 |

> 如果本机已经有 `%LOCALAPPDATA%\QQAgentVoice\config.json`（「自训练语音回复」用的那份），
> 插件会自动读取并复用它的 `voices` 配置，上面三项可以不填。

填完不用重启：插件页点「刷新」就能看到状态从「依赖未满足」变成正常。

## 「底模」和「训练模型」都行

GSV 推理界面里能选的**底模（预训练模型）**，这里同样能用 —— 那两个权重字段接受**任意**权重路径，
不限于你自己训练的。两者效果完全不同：

| | 训练模型（例：`AiLiSi-e15.ckpt` + `AiLiSi_e18_s486.pth`） | 底模（预训练） |
|---|---|---|
| 音色来自 | **训练时学到的那个角色**，参考音频只提供语气/情绪 | **完全由参考音频决定**（零样本克隆）——给谁的声音就学谁 |
| 想换音色 | 得重新训练 | 换一段参考音频 + 改参考文本就行 |

**怎么填底模**：先把「GPT-SoVITS 根目录」填上，然后两个权重字段可以直接填**相对路径**（会按根目录解析）：

| 版本 | GPT 权重（t2s） | SoVITS 权重 |
|---|---|---|
| **v2ProPlus** | `GPT_SoVITS/pretrained_models/s1v3.ckpt` | `GPT_SoVITS/pretrained_models/v2Pro/s2Gv2ProPlus.pth` |
| v2Pro | 同上 | `GPT_SoVITS/pretrained_models/v2Pro/s2Gv2Pro.pth` |
| v2 | `GPT_SoVITS/pretrained_models/gsv-v2final-pretrained/s1bert25hz-5kh-longer-epoch=12-step=369668.ckpt` | `GPT_SoVITS/pretrained_models/gsv-v2final-pretrained/s2G2333k.pth` |
| v1 | `GPT_SoVITS/pretrained_models/s1bert25hz-2kh-longer-epoch=68e-step=50232.ckpt` | `GPT_SoVITS/pretrained_models/s2G488k.pth` |
| v4 / v5 | `GPT_SoVITS/pretrained_models/s1v3.ckpt` | `gsv-v4-pretrained/s2Gv4.pth` / `gsv-v5-pretrained/s2Gv5turbo.pth` |

- ⚠️ **两个权重必须同一代**（v1 / v2 / v2Pro / v2ProPlus），混着填会加载失败或声音不正常。
- ⚠️ **别填 `s2D*` 开头的文件**（如 `s2Dv2ProPlus.pth`）——那是判别器，推理用不上。
- 服务端启动时用哪一代由 `GPT_SoVITS/configs/tts_infer.yaml` 里的 `version` 决定，要和权重对上。
- 绝对路径、相对路径都可以；相对路径按上面那个「根目录」解析。

## 语音接口：由插件开关控制（不需要任何脚本）

**插件的开关就是语音接口的开关**，两边永远一致：

| 你在插件页做的事 | 插件会做什么 |
|---|---|
| **打开插件** | 接口没在运行时，用你填的 python / api_v2.py 在后台把它拉起来（首次约 40 秒加载模型，不弹黑窗口） |
| **关掉插件** | 让接口**自己退出**（发 `GET /control?command=exit`），端口和显存立刻释放，通常 1 秒内完成 |
| 关掉后又打开 | 接口重新拉起来；退避计数会清零，所以是立刻开始，不会"要等 5 分钟" |

细节：

- 接口**已经在跑**（你自己开的、或上次留下的）→ 插件直接复用，不会重复启动一个。
- 关插件时**只关本机的接口**。`API 地址` 填的是 `192.168.x.x` 或域名（共享/远程的接口）时不会去关它。
- 你的接口如果不支持 `/control`（不是 gpt-sovits 的 api_v2.py），关插件时不会误杀它，只会在
  `runtime.log` 里记一句"发了退出指令但端口一直没释放"。
- 补丁本身不会被摘掉：它每次发送前都会问"插件还开着吗"，关掉就自动放行文字。

> ⚠️ `go-webui.bat` **不是**语音接口。它开的是 GPT-SoVITS 的网页调音台（端口 9874），
> 跟插件要的 9880 是两个不同的程序，开它插件一样发不出语音。

## 想彻底停掉语音接口

**直接把插件开关关掉就行**——这是唯一需要做的动作。

如果关闭时接口没退出（日志里写了原因），再手动处理：

| 办法 | 说明 |
|---|---|
| 任务管理器 | 详细信息 → 找到 `python.exe` → 结束任务。**插件自动拉起的那个没有窗口**（特意隐藏的），所以关不了窗口 |
| 命令行 | `netstat -ano \| findstr :9880` 拿到 PID，再 `taskkill /PID <pid> /F` |

> 注意：只要插件开关还开着、「接口没运行时自动帮你启动」也开着，下次（或下条要发语音的消息）
> 它会把接口再拉起来——这是设计如此。想让它一直停着，就把插件开关关掉。


## 行为开关（都有默认值，一般不用改）

- `maxChars`：超过这个字数就不转语音、直接发文字（默认 60）。QQ 语音太长会被拒收，念出来也像念稿。
- `skipStructured`：含链接、代码块、CQ 码、文件路径的内容仍发文字（默认开）。
- `allowPrivate` / `skipChats`：控制私聊、指定群是否转语音。
- `maxPerMinute`：每分钟最多合成几条（默认 10），超出的当次发文字。
- `alsoSendText`：语音之外再补一条同样的文字（默认关）。
- `pathStyle`：先试 `file:///` 还是裸路径；两种都会自动重试，还不行会试 `base64://`。
- **`deleteAfterSend`（默认开）**：语音发给协议端之后，本地那份 wav **立刻删除**，硬盘上不留东西。
  关掉则会按内容缓存复用（同一句话不用重复合成、更快），代价是文件要等 `fileTtlMinutes` 到了才清。
- `timeoutMs` / `fileTtlMinutes`：单条合成超时；`fileTtlMinutes` 只在关掉上面那个开关时才有意义
  （另外每次启动插件会按它清扫一次上一轮遗留的文件）。
- `autoStartApi`（默认开）：接口没在运行、插件又开着时，要不要由插件把它拉起来。
  关掉它 = "接口我自己管"：插件只负责探到端口就用，不会启动也不会关掉任何东西。

## 硬盘上会留下什么

- **没配置过**（比如装上了但还没填参考音频）：**一个文件都不会有** —— 连
  `data/sovits-voice-reply/` 这个目录都不会被创建。配置之后才会开始建目录、写日志。
- **配置之后**：目录里只有 `runtime.log`、`api-server.log`（接口自己的输出，接口正常时可能是空的，
  python 会把输出先攒在缓冲里）、你指定的参考音频（如果放在这里）、以及 `voice/`。
- **`voice/`**：默认"发完就删"，正常情况下**一直是空的**。每次启动插件还会扫一遍上一轮
  万一没删掉的残留（超过 1 分钟的）。

## 排查：为什么这条没发语音

插件**自己写运行日志**（重要：插件打给开发者控制台的东西不会进 QQ Agent 的项目日志，
所以必须看这里）：

| 文件 | 看什么 |
|---|---|
| `data/sovits-voice-reply/runtime.log` | 每次判定结果：`已发语音` / `跳过（原因）` / `失败（原因）`，以及接口的启动过程 |
| `data/sovits-voice-reply/api-server.log` | 自动启动的语音接口自己的输出。接口起不来时看这里 |

`runtime.log` 长这样：

```
2026-10-09 21:21:38 [加载] 已加载（上限 60 字，每分钟 10 条，自动启动接口=开）
2026-10-09 21:21:38 [启动] 已拉起语音接口（pid 7540）：...\runtime\python.exe
2026-10-09 21:22:14 [启动] 语音接口已就绪（用了约 36 秒）
2026-10-09 21:22:34 [已发语音] zh｜18 字｜耗时 55.7s｜group:123456｜「自动启动测试…」
```

| 插件页显示 | 含义 |
|---|---|
| `依赖未满足：尚未配置音色…` | 参考音频/参考文本没填全 |
| `依赖未满足：文件不存在：…` | 路径填错，或模型文件被移动了 |
| `加载失败：…` | 入口/清单有问题，看插件页红色那行原文 |
| 状态正常但群里还是文字 | 打开 `runtime.log`，里面写明了是"跳过"还是"失败"以及原因 |

同一条原因最多每 5 分钟记一次（否则"超过 60 字"这种会一分钟刷十几行，把真问题淹掉）。

## 分享给别人 / 换一台电脑

**这个插件目录是自包含的，可以直接打包发人**：它不依赖任何 npm 包，只用 Node 内置模块和
QQ Agent 自己的 `src/`；所有落盘位置都通过 `DATA_DIR` 和 `%LOCALAPPDATA%` 推导，**没有任何写死的本机路径**。

也**不需要任何 bat / 启动脚本** —— 启停由插件开关控制；你发出去的只有
`plugins\sovits-voice-reply\` 这一个文件夹。

对方需要做的：

1. 装好 QQ Agent（要支持 `plugins/` 目录的那一代）；
2. 把整个 `sovits-voice-reply` 文件夹放进 **他的** `<QQ Agent 安装目录>\resources\app\plugins\`
   （装在 `Program Files` 下需要管理员权限）；
3. 有一个能用的 GPT-SoVITS HTTP 接口（默认认 `http://127.0.0.1:9880`）；
4. 在插件设置里填**两项**：参考音频 + 参考文本。**权重可以留空**（用接口端已加载的那份），
   没训练过模型的也能用（零样本克隆）；
5. 想连接口都不用管，就把 python / api_v2.py / 工作目录三个路径也填上 ——
   之后**打开插件就等于打开接口**，关掉插件接口也跟着退出；不填这三个路径的话，
   就自己先把接口开起来，插件探到端口会直接复用；
6. 白名单里加上要说话的群或私聊。

**千万别一起发的东西**：`data\config.json`（含模型 API Key、群号、白名单、群友记忆）和
你的参考音频（发出去等于把音色给别人）。只发 `plugins\sovits-voice-reply\` 这一个文件夹就够。

## 和「自训练语音回复」的区别

老那份（`plugins/self-trained-voice-reply/`）是个**技能型工具**：由模型自己决定什么时候发语音，
而且安装包解压多套了一层目录（`self-trained-voice-reply/voice-reply/plugin.json`），
加载器读不到清单，日志里会报「缺少 skill.json / plugin.json」。

本插件是**确定性型**：不需要模型判断，所有该发的回复都转语音。
两者可以共存，但同时开会重复发语音 —— 建议只留一个。
