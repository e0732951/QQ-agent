今日塔罗 v3.0.0 —— 安装必读（给人看）

这个插件干什么：
给群里加一个每日占卜玩法——抽塔罗牌、出成一张图直接发到群里。不碰人设、不碰记忆，纯玩。


一、v3 比上一版多了什么

1. 每天抽的牌从两张变成三张：
   · 大阿卡纳 = 今天的"主题"
   · 小阿卡纳 = 今天的"事件"
   · 宫廷牌（共 16 张：侍从 / 骑士 / 王后 / 国王 × 权杖 / 圣杯 / 宝剑 / 星币）= 另一个维度的信息
   三张各判正逆位，合成一张图发到群里。

2. 图一里多了一块"宫廷"说明：牌名、正逆位、核心词、以及它代表的意思。
   注意：图一仍然只给牌面和含义，不给建议（建议只属于"抽签解读"那张图）。

3. "抽签解读"那张图的版面没变，只在最后的"最终建议"里多了一段"宫廷指引"。

4. 内部测试指令也同步支持宫廷牌了（普通用户用不到）。


二、装之前要准备什么

1. 需要先装"指令前置"插件，并且它要开着。
   它的作用是识别并分发这四条指令；没装的话这些指令不会有人接。
2. 程序要能开窗口（桌面版正常版就行）。
   出图是借用程序自己的窗口渲染的，纯命令行版本会退化成只回文字。


三、怎么装（三步）

1. 把插件本体文件夹（jy-tarot）整个复制到程序的 plugins 文件夹里。
   注意是整个文件夹，不要只复制里面的文件；里面的 data 和 assets 两个文件夹也要带上。
2. 打开程序，设置 → 插件，找到"今日塔罗"，打开开关。
3. 完全退出程序，再重新打开（大退重开，不是最小化，也不是刷新）。

指令前缀默认是 /，也就是在群里发 /今日塔罗、/抽签解读。
（如果你的"指令前置"改过前缀，就按你改的那个来。）


四、装完怎么确认（三条）

1. 设置 → 插件里能看到"今日塔罗"，状态是"已启用"，没有"依赖未就绪"。
2. 群里发 /今日塔罗，有回应（图片或文字）——说明指令接通了。
3. 回复的是一张图，图上是三张牌（主题 / 事件 / 宫廷）——说明出图正常。
   如果只回文字，通常是大退重开一次就好。


五、四条指令

1. 今日塔罗 —— 抽三张牌（主题 / 事件 / 宫廷），出图。每人每天一次；
   重复发会把今天已经抽到的那三张再发一遍，不会重新抽。
2. 抽签解读 —— 在先抽过今日塔罗的前提下，再抽一支签（凶 / 末吉 / 吉 / 中吉 / 大吉），
   和当天的牌组合成最终建议，并在建议末尾附一段宫廷指引。
3. 测塔罗 —— 内部测试用，不记账、可反复抽、可以指定牌号和正逆位。
   只在测试白名单里的人能用。
4. 测抽签 —— 内部测试用，指定签位出图。也只在白名单里能用。


六、常见问题

1. 发指令完全没反应？
   先看"指令前置"是不是开着，再看前缀是不是 /，最后看本插件的开关。

2. 只回文字不出图？
   大退重开一次。还不行的话，看程序日志里有没有这个插件的警告。

3. 提示"素材缺失 N 张"？
   说明 assets 文件夹没换全（这一版新增了 32 张宫廷牌图片）。
   把新版整个文件夹重新覆盖一遍，不要只替换 js 和 json。

4. 图里只有两张牌？
   说明 lib 文件夹还是旧版。整包替换，别只换 index.js。

5. 抽签解读说"抽取塔罗后才可抽签解读哦"？
   说明当天还没抽过塔罗（或者换人了）。先发 /今日塔罗。

6. 升级当天有人说"我明明抽过了，怎么又能抽"？
   这是正常的：旧版本的记录没有宫廷牌，新版认不出来，就当作今天没抽过，让他重抽一次就好。
   从第二天起就恢复"每天一次"。

7. 想一天多抽几次？
   在插件设置里把"每人每日抽取上限"调大（最大 9）。

8. 改完设置不生效？
   大退重开一次程序。

这一版不算 bug 的地方（先看一眼，省得误会）：
· 牌库不是完整 78 张：大阿卡纳 22 张齐全；小阿卡纳只有 20 张（四种花色 × Ace/3/6/9/10）；
  宫廷牌 16 张。其他点数不在牌库里。
· 同一个人同一天抽到的牌是固定的，反复发也是同一组。这是故意的，
  不然反复发"抽签解读"就能刷到大吉，签就没意义了。


七、升级与卸载

升级：把 plugins 里的 jy-tarot 整个文件夹替换成新版本（连同 data 和 assets 一起换），然后大退重开。
卸载：删掉整个 jy-tarot 文件夹，或者在设置里关掉开关。
